A collection of 150+ creative CSS and JavaScript animation projects completed while taking the course [Creative Advanced CSS Animations – 150 Projects](https://www.udemy.com/course/css-animation-transitions-and-transforms-creativity-course/). This repository showcases modern animation techniques through hands-on projects covering transitions, transforms, keyframes, hover effects, loaders, navigation menus, cards, and interactive UI components.

Serving as both a learning archive and a portfolio, these projects explore how motion and interactivity can enhance user experiences in modern web applications. The focus is on building practical animation skills while developing a strong foundation in creative frontend design.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
